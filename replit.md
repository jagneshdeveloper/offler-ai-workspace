# Replit development

This project is a TanStack Start application managed with Bun.

## Run the app

- Install dependencies with `bun install --frozen-lockfile`.
- Start the development server with `bun run dev -- --host 0.0.0.0 --port 5000`.
- The Replit `Start application` workflow runs that development command automatically.

The Vite configuration comes from `@lovable.dev/vite-tanstack-config`, which handles the development host and port settings. Keep the existing Lovable/TanStack structure intact.
